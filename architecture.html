🦉 Math Buddy — Architecture Overview

High-level technical overview for contributors and collaborators · June 2026

What is Math Buddy?

Math Buddy is a pure static web app — there is no backend server. It is a single-page application (HTML + CSS + JS) that calls the Anthropic Claude API directly from the user's browser. The app is hosted for free on GitHub Pages and deployed automatically via GitHub Actions every time code is pushed to the branch.

The app acts as a Socratic math tutor for Nick, a 4th/5th-grade student working through the Eureka Math curriculum. It has a homework chat mode and a timed test/assessment mode, both powered by Claude.

The 7 App Screens

🔑 API Key Screen

First-time setup. Shown only if no API key is found (neither baked in via deploy nor saved in localStorage). User pastes their Anthropic key; it's stored in localStorage.

🦉 Login Screen

Login or register. Accounts are stored entirely in localStorage. Passwords are SHA-256 hashed with a salt via the browser's crypto.subtle API — no server involved.

⚙️ Setup Screen

Student picks their module and lesson, then types or photographs their homework problem. Choosing "Let's Go!" launches the chat screen with the correct lesson context injected.

💬 Chat Screen

The main tutoring interface. Sends a system prompt (with lesson context and Socratic rules) plus the student's problem to Claude and streams the response back in real time.

🎯 Test Screen

15-minute timed assessment. Claude generates grade-appropriate questions across all modules. At the end, Claude produces a JSON report card parsed by the app.

📊 Report Card Screen

Displays the parsed JSON report: per-topic scores, skill levels (proficient / developing / needs support), common mistakes, and suggested practice problems.

👤 Profile Screen

Student can change their display name, grade, avatar (31 forward-facing animal + accessory combos), and password.

How the API Call Works

⚠️ Security note: The API key is exposed in the browser. This is acceptable for a private family app but would not be appropriate for a public app with many users. The header anthropic-dangerous-direct-browser-access: true is required precisely because Anthropic knows this is a browser-side call.
1
Student selects module + lesson (e.g. Grade 4, Module 3, Lesson 12). buildSystemPrompt(module, lesson, grade) assembles a detailed system prompt containing the lesson objective, module overview, Socratic tutoring rules, and an instruction to proactively present a practice problem.
2
App POSTs to api.anthropic.com/v1/messages with the system prompt, the student's message, and stream: true. The model is claude-opus-4-5.
3
Response streams back as Server-Sent Events (SSE). The app reads each content_block_delta chunk and appends it live to the chat bubble so the student sees the response as it's generated.
4
Test mode only: at the end of the test, Claude's final message includes a JSON block between ===REPORT_CARD_START=== and ===REPORT_CARD_END=== markers. The app extracts and parses this to render the Report Card screen.

Lesson Data Structure

The entire Eureka Math curriculum (Grade 4 + Grade 5 Module 1) is hard-coded in script.js as JavaScript objects. There are 135 Grade 4 lessons and 16 detailed Grade 5 lessons.

Each module entry looks like:

LESSON_MAP[3] = {
  name: "Multi-Digit Multiplication and Division",
  totalLessons: 43,
  moduleOverview: `Tools: area model, place value disks...
Key vocabulary: factor, product, quotient...`,
  lessons: {
    12: "Explaining how the area model relates to the standard
         algorithm for two-digit × two-digit multiplication...",
    ...
  }
}

The test topics (TEST_TOPICS_G4 / TEST_TOPICS_G5) are separate arrays — each entry has a module reference, topic name, and detailed guidance string that tells Claude exactly what to ask at each difficulty level (straightforward / medium / harder).

User Authentication & Data

There is no backend database. All user data lives in the browser.

StorageKeyContents
localStoragemathbuddy_usersJSON array of user objects: username, displayName, grade, avatar, hashed password, test history
localStoragemathbuddy_apikeyAPI key fallback (if not baked in via deploy)
sessionStoragemathbuddy_sessionCurrently logged-in username (clears on tab close)
⚠️ Data portability: Because data lives in localStorage, it is tied to the specific browser and device. Clearing browser data or switching devices loses all accounts and history.

Avatar System

Avatars are composed of two parts:

  • Animal base: 31 Twemoji SVG images fetched from the jsDelivr CDN (twemoji@14.0.2). All are forward-facing so accessories sit naturally.
  • Accessory overlay: An emoji (crown 👑, glasses 🕶️, bow 🎀, etc.) absolutely positioned over the animal using CSS. 12 accessory options including "None".

The animalAvatarHtml(cp, accessoryId, size) function builds a <div> with a relative-positioned container, the animal <img>, and a <span> for the accessory. Avatar choice is stored per-user as avatarAnimal (codepoint string) and avatarAccessory (accessory id string).

Deployment Pipeline

1
Developer pushes code to branch claude/homework-helper-app-9nqN1 (or main/master)
2
GitHub Actions runs deploy.yml, which creates config.js containing window.MATHBUDDY_KEY = '[secret]'; from the ANTHROPIC_API_KEY repository secret
3
All files (including the generated config.js) are uploaded to GitHub Pages via actions/upload-pages-artifact and deployed via actions/deploy-pages
4
Live site at greens80.github.io/Eureka_Math/ updates within ~60 seconds
✅ The secret is never committed to git. It only exists in the deployed artifact served by GitHub's CDN.

Running Locally

Because the app calls the Anthropic API from the browser, it needs HTTPS or localhost to work. The simplest local setup:

# 1. Clone the repo
git clone https://github.com/commonrule/Eureka_Math.git
cd Eureka_Math

# 2. Create config.js with your API key
echo "window.MATHBUDDY_KEY = 'sk-ant-...your-key...';" > config.js

# 3. Serve locally (any static server works)
npx serve .
# or: python3 -m http.server 8080

Then open http://localhost:3000 (or whichever port) in your browser.
